# CS4015 Software engineering and testing for AI systems

This folder contains the code of group B for training a good and bad model and testing them, alongside testing the other team's models (in the same file).

#
### <u> Running the tests </u>

In the Test folder, there is a singular Jupyter Notebook, which you just have to run once to obtain diagnostic information on all tests for both sets of models, alongside the final count of tests passed versus failed. Since we are averaging results over sampled runs, they should be pretty robust, so just running it once should end up in results similar to those reported.
